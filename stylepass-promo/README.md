# 스타일 패스 평생할인 이벤트 · 개발팀 전달본

Figma 시안(노드 1347:189)을 기준으로 구현한 정적 HTML/CSS/JS 페이지입니다. 빌드나 패키지 설치가 필요하지 않습니다.

## 배포

- 이 폴더(`stylepass-promo/`)를 통째로 파일서버에 올리고 `index.html`을 엽니다.
- 이미지·CSS·JS·성과 페이지 사본은 모두 상대경로입니다. 하위 경로 어디에 두어도 됩니다.
- 폰트는 웹폰트(jsDelivr CDN)만 사용하며, 로컬 폰트 파일은 없습니다.
  - Pretendard: dynamic subset CSS를 씁니다. 화면에 쓰인 글자 구간만 내려받습니다.
  - Paperlogy: 쓰는 굵기 4종(400/500/700/800, 각 약 160KB)만 선언했습니다.
- 페이지 최대 폭은 480px, 기준 시안 폭은 390px입니다.

## 결제 연결 (앱 결제 페이지 이동)

하단 고정 버튼과 성과 시트 안 버튼("스타일 패스 평생 할인 혜택 받기")은 이전 스타일 패스 평생할인 페이지(`event_chuseok.html`)와 **같은 코드, 같은 상품**을 씁니다.

```js
// index.html 하단 인라인 스크립트
join('mb_st.am1c4', 38, 24000);
// → window.flutter_inappwebview.callHandler(
//     "thinkpool_webview_handler", "webToApp_goLandingPageExp",
//     { landingPage: "LPHT", productId: "mb_st.am1c4", discountPct: 38, discountAmt: 24000 });
```

일반 브라우저에서는 결제 화면이 열리지 않고, 콘솔 경고("Flutter handler not found.")만 남습니다.

## 스타일 성과 바텀시트

"스타일 성과 자세히 보기" 버튼을 누르면 아래에서 시트가 올라오고, 시트 안에 성과 페이지가 열립니다. 동작은 엑스퍼트 소개 시트와 같습니다.

- **성과 페이지**: `portfolio/style_portfolio.html`
  - 원본 https://files.thinkpool.com/rassi_signal/style/style_portfolio.html 의 사본(2026-09-23 수정본)입니다.
  - 원본과 다른 점은 폰트 CSS를 dynamic subset으로 바꾼 것 하나뿐입니다.
  - 누른 버튼의 탭(황금값어치/황금코어)이 선택된 상태로, 맨 위부터 보여 줍니다.
- **스크롤 진행 막대**: 버튼 영역 윗변의 2px 보라 막대가 내려 본 만큼 차오릅니다.
  - 끝에 닿으면 '틱!' 효과가 나오고, 100%인 동안 버튼 글자가 노랗게 켜집니다.
- **닫기**: 닫기 버튼, 바깥 영역, Esc, 안드로이드 뒤로가기로 닫힙니다.
  - 열려 있는 동안 뒤 페이지 스크롤은 잠깁니다.
- **진행 막대가 보이는 조건**: 성과 페이지 사본이 이벤트 페이지와 **같은 서버(같은 출처)**에 있어야 합니다.
  - 폴더째 올리면 자동으로 충족됩니다.
  - `index.html`을 PC에서 파일로 직접 열면 막대만 숨겨지고, 나머지는 그대로 동작합니다.
- **원본 주소를 직접 쓰려면**: `index.html`의 `.sheet-frame` `data-src`를 원본 주소로 바꿉니다.
  - 이 경우 다른 출처면 진행 막대가 나오지 않습니다.

### 앱팀 확인: 안드로이드 뒤로가기 (expert-promo와 같은 방식)

웹에 `window.onAppBackPressed()`가 있습니다.

- 시트가 열려 있으면 시트를 닫고 `true`를 돌려줍니다.
- 시트가 닫혀 있으면 `false`를 돌려줍니다.

앱이 WebView를 닫기 전에 이 함수를 먼저 호출해야 뒤로가기로 시트만 닫힙니다. expert-promo 때 반영했다면 추가 작업은 없습니다.

```dart
final handled = await webViewController.evaluateJavascript(
  source: "window.onAppBackPressed ? window.onAppBackPressed() : false");
if (handled != true && context.mounted) Navigator.of(context).pop();
```

## 혜택 기간과 남은 시간

- **기간 리본**: "혜택 기간 ~ 10월 29일(목)". 키비주얼 하단 캐러셀 점 아래에 있습니다.
  - 날짜를 바꿀 때는 `index.html`의 `.period-static`과 `.period-track`의 세 번째 문구, 두 곳을 고칩니다.
  - 아래로 스크롤해 그 자리를 지나면 화면 상단에 고정되고, 가로로 펼쳐지며 안내 문구 3개가 롤링됩니다.
  - 고정 4초 뒤 닫기(×) 버튼이 나타납니다. 닫으면 이번 방문 동안 다시 고정하지 않습니다.
- **혜택 남은 시간**: 하단 버튼 6px 위 가운데에 "혜택 남은 시간 : 00일 00시간 00분 00초"를 1초마다 갱신해 표시합니다.
  - 글자는 진한 검정(#222), 숫자만 빨간색(#f03e3e)입니다.
  - 마감은 **2026-10-30 00:00 한국시간**입니다. `.sign-up-countdown`의 `data-deadline`에서 바꿉니다.
  - 마감 후에는 "혜택 기간이 종료되었습니다"로 바뀝니다.

## 화면 효과

- **TOP 15**: 색이 다른 "15" 이미지 5장을 같은 자리에서 즉시 교체(매치컷)합니다. 리듬은 엑스퍼트 할인율 카운트업과 같습니다.
  - 첫 바퀴는 빠르게, 둘째 바퀴는 0.28 → 0.76초로 점점 느려지다가 첫 장(검정)에서 멈춥니다. 반복하지 않습니다.
  - 리듬은 `js/top15.js`의 `DELAYS`에서 바꿉니다. 개수는 5의 배수로 유지해야 합니다.
- **뷰포트 진입 애니메이션**: 주요 블록이 화면에 들어오면 아래에서 살짝 떠오르며 나타납니다(한 번만).
  - 대상은 `data-reveal`이 붙은 요소입니다. 처음 화면에 보이는 요소는 바로 나타납니다.
  - 스크립트가 없거나 3초 안에 준비되지 않으면 숨김 없이 그대로 보입니다.
- **안내 카드 캐러셀**: 스와이프 한 번에 한 장씩 넘어가고, 처음과 끝에서 멈춥니다(반복 없음).
  - 점 탭으로 이동할 수 있고, PC에서는 마우스로 끌어 넘깁니다.
- **성과 맛보기 탭**: 흰 선택 배경이 선택한 탭 쪽으로 미끄러집니다(슬라이딩 탭).
- **마지막 섹션 체크 뱃지**: 엑스퍼트 '라씨의 선택' 따봉 아이콘과 같은 효과입니다. 튀어 오르며 나타난 뒤, 보이는 동안 3.2초마다 위로 튀며 흔들립니다.
- **혜택가 숫자 롤링(14,800원)**: pocketfolio 총자산 금액과 같은 토스식 롤링입니다. 자리마다 0~9 숫자 띠가 0에서 목표 숫자까지 1초 동안 굴러 올라갑니다(자리마다 0.045초씩 늦게 출발).
  - 숫자 전체가 하단 고정 버튼 위로 다 보이는 순간 한 번 시작하고, 그 전에는 0에서 멈춰 있습니다.
  - 다 굴러가면 원래 글자로 되돌립니다. 멈춘 뒤 모습은 정적 숫자와 같습니다.
  - 가격을 바꿀 때는 `index.html`의 `data-odometer`가 붙은 `<strong>` 안 숫자만 고칩니다.
- **"오늘 시장은?" 말풍선**: 그림이 하단 버튼 위로 60% 이상 보이면 말풍선이 크게 떠 있다가 스티커처럼 '탁' 붙습니다(한 번).
- **마지막 섹션 흐름도**: "N개 종목스타일 조합 → 22개 파워스타일 완성"이 왼쪽부터 원 → 화살표 → 박스 순서로 0.28초 간격을 두고 미끄러지며 나타납니다(한 번).
- **모션 감소 설정**: 위 효과를 모두 끄고 최종 상태로 보여 줍니다.
- **갤럭시 폴드 펼침·태블릿**: `js/foldable-fit.js`가 480px 디자인을 화면 폭에 맞춰 확대합니다(expert-promo와 동일).
- **하단 안전 영역** `--safe-bottom`은 기본값이 0입니다(이전 페이지와 동일).
  - 시스템 영역까지 덮는 전체 화면 WebView에 쓸 때만 `:root{--safe-bottom:env(safe-area-inset-bottom,0px)}`로 바꿉니다.

## 구성

- `styles/event.css`: 전체 스타일
- `js/foldable-fit.js`: 폴드·태블릿 화면 폭 맞춤
- `js/fit.js`: 좁은 화면에서 고정 크기 일러스트 축소
- `js/reveal.js`: 뷰포트 진입 애니메이션
- `js/top15.js`: TOP 15 매치컷
- `js/guide-carousel.js`: 안내 카드 캐러셀
- `js/event-period.js`: 혜택 기간 리본
- `js/performance-tabs.js`: 성과 맛보기 슬라이딩 탭
- `js/countdown.js`: 혜택 남은 시간
- `js/portfolio-sheet.js`: 스타일 성과 바텀시트
- `js/closing-badge.js`: 마지막 섹션 체크 뱃지 효과
- `js/price-odometer.js`: 혜택가 숫자 롤링
- `js/intro-bubble.js`: "오늘 시장은?" 말풍선 스티커 효과
- `js/closing-flow.js`: 마지막 섹션 흐름도 순차 표출
- `portfolio/style_portfolio.html`: 성과 페이지 사본
- `assets/images`, `assets/icons`: Figma 원본 이미지와 SVG
- `assets/images/performance`: 성과 맛보기 차트와 종목 로고

## 검수 결과

- **화면 폭** 280·320·344·360·375·390·412·430·480·1280px: 가로 넘침과 글자 넘침이 없고, 이미지는 모두 로딩되며, 웹폰트 8종이 적용됩니다.
- **390px 시안 대조**: 섹션 높이는 시안과 1px 이내이고(유의사항 영역은 행간 반올림으로 3px 이내), 문구 줄바꿈과 좌우 폭이 시안과 같습니다.
- **실제 터치 입력과 서버 환경 검수**:
  - 캐러셀이 한 장씩 넘어가고 끝에서 멈춥니다.
  - 기간 리본이 고정되고, 4초 뒤 닫기 버튼이 나오며, 닫으면 원위치로 돌아갑니다.
  - 슬라이딩 탭이 동작합니다.
  - 성과 시트: 열기, 스타일 지정, 진행 막대 0→50→100%, 틱, 버튼 글자 강조, 닫기·뒤로가기·Esc를 확인했습니다.
  - 체크 뱃지 효과와 남은 시간 갱신을 확인했습니다.
  - `join()` 호출 값이 이전 페이지와 같습니다.
