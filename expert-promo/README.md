# Expert 프로모션 · 개발팀 전달본

4배율 디자인 이미지 `expertpromo.jpg`와 확보한 Figma 레이어 규격을 기준으로 구현한 정적 HTML/CSS/JS 페이지입니다.

## 실행 및 전달

`index.html`을 브라우저에서 열거나, 이 폴더 전체를 웹서버의 원하는 하위 경로에 배치하세요. 별도 빌드나 패키지 설치가 필요하지 않습니다.

- 이미지, SVG, CSS, JS는 상대경로로 연결했습니다. 폰트는 외부 CDN을 참조합니다.
- 이미지와 SVG는 Figma에서 확보한 원본 파일이며, 임시 Figma 주소를 사용하지 않습니다.
- Pretendard와 Paperlogy는 jsDelivr CDN의 WOFF2를 `@font-face`로 로딩합니다. 400/500/600/700 굵기와 `font-display:swap`을 적용했습니다. 로컬 폰트 파일은 포함하지 않습니다.
- 페이지 최대 너비는 480px, 기준 시안은 375px입니다.
- 문구와 버튼은 HTML, 배치와 장식은 CSS로 구성했습니다. 전체 시안 이미지를 페이지에 붙이지 않았습니다.

## 타이머 및 버튼 효과

- 마감: **2026-10-02 23:59:59 한국시간(+09:00)**. `js/config.js`의 `deadline`에서 변경합니다.
- 하단 고정 타이머는 매초 갱신하며 마감 이후 ‘종료됨’을 표시합니다. 바 높이와 안전 영역에 필요한 여백은 푸터 내부에 확보하며 푸터 아래 별도 여백은 없습니다.
- 네 버튼 문구는 ‘평생반값 혜택받기’입니다. 첨부 HTML과 같은 민트색 2.6초 샤인 효과를 적용했습니다.

## 결제 연결 — 개발팀 필수 설정

각 버튼은 `join(expertId, productId, discountPct, discountAmt)`를 통해 아래 앱 핸들러를 호출합니다.

```js
window.flutter_inappwebview.callHandler(
  'thinkpool_webview_handler',
  'webToApp_goLandingPageExp',
  { landingPage: 'LPTP', expertId, productId, discountPct, discountAmt }
);
```

`js/config.js`의 `products`에 사용자가 전달한 전문가별 값을 반영했습니다. 공통값은 `discountPct: '55'`, `discountAmt: '220000'`입니다. 사용자 정정에 따라 기존 금액을 유지합니다.

| 설정 키 | 전문가 | expertId | productId |
|---|---|---|---|
| `surge-hunter` | 서지헌터 | `ebirang22` | `rc_e15.am1d5` |
| `trader-shin` | 트레이더신 | `kkmad111` | `rc_e14.am1d5` |
| `absolute-wealth` | 절대부유 | `ixtous` | `rc_e11.am1d5` |
| `gold-spoon` | 금수저 | `acafera` | `rc_e13.am1d5` |

상품코드는 `rc_e번호.am1d5` 형식입니다. 절대부유는 기존 `_11`을 다른 전문가와 같은 형식인 `rc_e11.am1d5`로 맞췄습니다.

버튼 클릭 시 원본 코드처럼 앱 핸들러를 즉시 호출합니다. 응답 대기나 시간제한을 적용하지 않습니다. 앱 브리지 없음 또는 핸들러 오류는 토스트로 표시합니다. 일반 브라우저에서는 Flutter 결제화면을 열 수 없습니다.

버튼은 `join()`을 직접 호출하며 기존 중간 취소 이벤트는 사용하지 않습니다.

서비스 소개의 선택 안내는 전문가 섹션으로 스크롤하고, 고객센터 전화번호는 `tel:` 링크입니다. 카카오톡 채널 URL은 제공되지 않아 원본처럼 텍스트 안내로 유지했습니다.

## 앱 헤더가 있는 WebView의 상단 여백

- 제공된 실제 앱 화면에 맞춰 스티키의 상단 추가 inset 기본값을 0으로 변경했습니다. `--sticky-safe-top:0px`로 높이 42px, 문구 수직 중앙, 닫기 버튼 top 0을 유지합니다.
- 앱이 상단 안전 영역을 처리하지 않는 전체화면 WebView에 재사용할 때만 `:root{--sticky-safe-top:env(safe-area-inset-top,0px)}`로 설정하세요. 하단 안전 여백은 그대로 유지합니다.
- 모의 기기 상단 inset 47px에서도 띠 높이 42px, 텍스트 중앙 21px 확인: sticky-inset-verification.json.
- 화면 상단의 흰색 네이티브 닫기 헤더는 HTML 바깥이므로 이 CSS 수정 대상이 아닙니다.

## 갤럭시 폴드 대응 및 가격 카드 보정 (2026-09-30)

- `js/foldable-fit.js`: 짧은 변이 560px 이상인 기기(갤럭시 폴드 펼침, 태블릿)에서 viewport를 480px로 지정해 디자인 전체를 화면 폭에 맞춰 확대합니다. 확대 배율은 최대 1.85배이며, 이를 넘는 가로 화면에서는 480px 본문을 가운데 둡니다. 접기·펼치기·회전 시 다시 계산합니다.
- 일반 폰(가로 모드 포함)과 PC 브라우저에는 영향이 없습니다. Android WebView는 `useWideViewPort`가 켜져 있어야 viewport 지정이 적용되며, Flutter InAppWebView 기본값은 켜짐입니다.
- 검수 폭: 280(폴드 접힘), 320, 344(폴드 접힘), 375, 673·882(폴드 펼침), 1104(펼침 가로), 844(가로 폰), 1280(PC). 가로 넘침·글자 넘침 없음, 접힘↔펼침 전환 확인.
- 가격 카드 높이 160 → 173px. 상하 여백과 정가·혜택가 간격만 늘렸고 글자 크기는 유지했습니다. (185px 적용 후 너무 높아 보여 173px로 조정)
- 할인율 플래그: 분홍 그라데이션을 진한 빨강 그라데이션(`#a3001c → #cf0a24 → #ee2a3c → #c4001d`)으로 교체했습니다. 각도·위치는 동일하며 흰 글자 대비가 높아졌습니다.
- 280px 폭에서는 가격 카드 제목과 할인율 플래그가 겹치지 않도록 제목을 15px로 줄입니다.

## 전문가 소개 팝업 (2026-09-30)

- 전문가 카드의 사진 영역(카드 오른쪽 48%)을 누르면 아래에서 전체 화면 시트가 올라와 서버의 소개 PNG를 보여 줍니다. 사진 오른쪽 아래 지름 28px 반투명 동그라미 안의 돋보기 아이콘으로 누를 수 있음을 알립니다. 카드가 화면에 3초 동안 보이면 왼쪽으로 펼쳐지며 ‘소개 보기’ 글자가 나타나고, 이후 펼친 상태를 유지합니다(`js/expert-intro.js`의 `EXPAND_DELAY`). 280px 폭에서는 결제 버튼과 겹치지 않도록 돋보기만 유지합니다.
- 이미지 주소: `js/config.js`의 `introImage` (`https://files.thinkpool.com/rassi_signal/expert/{expertId}_page.png`). `{expertId}`는 각 전문가 ID로 바뀝니다. 전문가별로 다른 이미지를 쓰려면 해당 `products` 항목에 `introImage`를 추가합니다.
- 시트 하단 버튼은 ‘**전문가명** 평생반값 혜택받기’로 표시하며, 카드 버튼과 같은 `join()`과 상품코드를 사용합니다. 카드 버튼과 달리 꺾쇠(>) 아이콘은 없습니다.
- 닫기: 닫기 버튼, 바깥 영역, Esc, 안드로이드 뒤로가기. 열 때 기록을 하나 추가하므로 뒤로가기는 팝업만 닫습니다. 앱이 뒤로가기를 `webView.goBack()`으로 처리해야 합니다.
- 하단 구매 버튼 영역 윗변에 2px 연초록 막대(#72e6a0)가 소개 이미지를 내려 본 만큼 왼쪽부터 차오릅니다.
- 막대가 끝에 닿으면 ‘틱!’ 이펙트가 약 0.5초 나옵니다. 눈에 띄지 않게 미묘하게 만들었습니다. 막대 끝이 살짝 밝아지고, 끝 지점에서 지름 12px 연초록 고리가 옅게 퍼지며 길이 4px 불꽃 4개가 8px 정도 위로 튑니다. 이펙트 중심은 막대 오른쪽 가장 끝 모서리이며, 팝업 경계에서 잘려 왼쪽 반쪽만 보입니다. 같은 순간 ‘전문가명 평생반값 혜택받기’ 글자만 2px 살짝 올라갔다가 돌아옵니다(버튼 테두리·배경은 그대로). 95% 아래로 올렸다가 다시 닿으면 또 나옵니다. 모션 감소 설정에서는 나오지 않습니다.
- 팝업 동안 뒤 페이지 스크롤을 막고, 팝업 본문의 스크롤바는 숨깁니다. 열 때마다 이미지 맨 위부터 보여 줍니다.
- 본문 스크롤바도 이전 페이지와 같이 숨깁니다. 스크롤 동작은 그대로입니다.
- 이미지는 사진을 누를 때만 받습니다. 누르는 순간부터 미리 받아 표시를 앞당기고, 한 번 받은 이미지는 다시 열 때 새로 받지 않습니다. 실패 시 안내 문구와 ‘다시 시도’ 버튼을 표시합니다.
- 캐시: 같은 페이지를 보는 동안은 재요청이 없습니다(검수 확인). 앱을 다시 열었을 때의 재사용은 서버 응답 헤더에 달려 있습니다. 현재 `Cache-Control`이 없고 `Last-Modified`·`ETag`만 있어, WebView가 임의 기간 캐시하거나 서버에 변경 여부를 확인(304)합니다. 명확히 하려면 서버에 `Cache-Control: public, max-age=86400` 등을 설정하세요.

## 할인율 카운트업 (2026-09-30)

## 버튼 탭 색상·팝업 가로 스와이프 (2026-09-30)

- 혜택받기 버튼(카드 4개와 팝업 버튼)의 hover 색은 마우스처럼 hover가 가능한 기기에서만 적용합니다. 터치 기기에서는 누르는 동안만 눌림 색이 보이고, 손을 떼면 원래 색으로 돌아옵니다.
- 팝업 본문은 본 페이지처럼 가로 넘침을 막고(`overflow-x:hidden/clip`), 가로 스와이프·가로 끌림 반동을 막아 세로 스크롤만 허용합니다(`touch-action:pan-y`, `overscroll-behavior-x:none`).
